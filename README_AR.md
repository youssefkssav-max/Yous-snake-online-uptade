# Yous Snake Online — المرحلة الأولى

هذه الحزمة مبنية على أحدث نسخة متاحة من اللعبة (المتاهات الـ13 والممرات الصحيحة)، وتضيف:

- زر Online داخل القائمة.
- إنشاء غرف عامة وخاصة.
- كود دخول للغرفة الخاصة.
- قائمة بالغرف العامة.
- حد أقصى 16 لاعبًا لكل غرفة.
- اختيار وضع الغرفة: عادي / منافسة / 1 ضد 1 / متاهة.
- شاشة انتظار تعرض اللاعبين والمضيف.
- خادم WebSocket مستقل مع endpoint للصحة `/health`.
- ملفات PWA: manifest وservice worker وأيقونة.

## تنبيه مهم عن المرحلة الحالية

هذه **المرحلة الأولى (الغرف واللوبي والاتصال)** وليست إصدار لعب أونلاين مكتملًا بعد. زر بدء المباراة يرسل حدث بدء إلى الغرفة، لكن مزامنة حركة الثعابين ومحاكاة اللعب المشتركة ونقل قواعد الأوضاع الأربعة ما زالت مرحلة التطوير التالية. لم يتم الادعاء باختبار مباراة حقيقية بين 16 جهازًا.

## تشغيل الخادم محليًا

يتطلب Node.js 20 أو أحدث:

```bash
cd server
npm install
npm start
```

يفتح الخادم على `http://localhost:3000`، وفحص الحالة:

`http://localhost:3000/health`

## نشر الخادم

انشر مجلد `server` على خدمة تدعم Node.js وWebSocket (مثل Render أو Railway):

- Build command: `npm install`
- Start command: `npm start`
- Port: استخدم متغير البيئة `PORT` الذي توفره منصة الاستضافة.

بعد النشر ستحصل على عنوان HTTPS، حوّل بدايته إلى `wss://` لاستخدامه داخل اللعبة.

## نشر واجهة اللعبة

ارفع محتويات مجلد `web` إلى جذر مستودع GitHub Pages. افتح اللعبة، اضغط Online، الصق رابط WebSocket في خانة رابط الخادم، ثم اضغط حفظ رابط الخادم والاتصال.

## اختبار الغرف

افتح اللعبة في متصفحين أو جهازين، اتصل بنفس رابط الخادم، أنشئ غرفة من الجهاز الأول، ثم ادخل بالكود من الجهاز الثاني. يجب أن يظهر اللاعبان في اللوبي. لا تبدأ اختبارًا تنافسيًا على أنه gameplay مكتمل؛ هذه المرحلة تختبر إنشاء الغرف والانضمام وإدارة الأعضاء فقط.
